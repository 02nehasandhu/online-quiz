# Online Quiz

This repository contains a simple HTML/JavaScript quiz app.

## About
- `online_quiz.html` is the main quiz page.
- The quiz loads questions dynamically from JavaScript.
- It includes score tracking, a timer, random question order, and an end-of-quiz summary.

## Run locally
1. Open `online_quiz.html` in a browser.
2. Or copy this path into the browser address bar:
   `file:///d:/my%20project/online_quiz.html`
